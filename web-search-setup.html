IBM · Build an Agent Workshop

Give Claude the power to search the web.

This guide walks you through installing the web-search MCP server and connecting it to Claude — from a fresh machine to a working setup. No prior command-line experience assumed.

⏱ ~10 minutes 🖥 macOS & Windows 🧩 Package: @guhcostan/web-search-mcp
Show steps for
Before you start: you'll need admin rights on your machine (to install software) and about 500 MB of free space. Everything below is free and open source.
1

Install Node.js

Node.js runs the MCP server, and it ships with npm, the tool you'll use to install it.

On macOS the cleanest way is via Homebrew, a package manager for the terminal. Open the Terminal app (press ⌘ + Space, type "Terminal", hit Enter), then run:

a · install Homebrew

Terminal — zsh
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Follow the prompts (it may ask for your password). When it finishes, it prints two echo commands under "Next steps" — copy and run those to add Homebrew to your PATH. Then install Node:

b · install node with homebrew

Terminal — zsh
$ brew install node

On Windows, the simplest path is the official installer — it includes npm automatically.

a · download & run the installer

Go to nodejs.org/en/download, download the LTS version for Windows (.msi), and run it. Accept the defaults — importantly, keep "Add to PATH" checked. When it finishes, close and reopen any open terminal windows so the changes take effect.

Tip: use PowerShell or Windows Terminal for the commands in this guide. Search for it in the Start menu.

verify it worked

Run these two commands. You should see a version number after each (e.g. v22.x.x). If you do, Node is installed correctly.

Terminal
$ node -v
$ npm -v
✓ Checkpoint: both commands print a version number. If you get "command not found", close the terminal, open a fresh one, and try again.
2

Install the web-search MCP server

One command installs it globally so Claude can find it.

Terminal
$ npm install -g @guhcostan/web-search-mcp
Permission error? If you see EACCES, it means npm can't write to the global folder. Re-run with the correct owner — avoid sudo; instead run sudo chown -R $(whoami) $(npm config get prefix)/{lib/node_modules,bin,share} once, then retry the install.

find where it installed

You'll need the full path to the installed program for the next step. Run:

Terminal — zsh
$ which web-search-mcp

On Apple Silicon this is usually /opt/homebrew/bin/web-search-mcp; on Intel Macs it's /usr/local/bin/web-search-mcp. Whatever it prints is what you'll paste below.

PowerShell
> where.exe web-search-mcp

This prints something like C:\Users\YOU\AppData\Roaming\npm\web-search-mcp.cmd. Copy that path for the next step.

3

Add it to your Claude config

Tell Claude to launch the server by editing one JSON file.

open the config file

Open (or create) the file at this path — the fastest way is to run:

Terminal — zsh
$ open -e "$HOME/Library/Application Support/Claude-3p/claude_desktop_config.json"

The file lives at ~/Library/Application Support/Claude-3p/claude_desktop_config.json.

Open (or create) the file at this path — run:

PowerShell
> notepad "$env:APPDATA\Claude-3p\claude_desktop_config.json"

The file lives at %APPDATA%\Claude-3p\claude_desktop_config.json. If Notepad asks to create it, say yes.

paste this configuration

Replace the command path if which gave you something different (e.g. /usr/local/bin/... on Intel):

claude_desktop_config.json
{
  "mcpServers": {
    "web-search": {
      "command": "/opt/homebrew/bin/web-search-mcp",
      "env": {
        "PATH": "/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin"
      }
    }
  }
}

Use the path where.exe printed. Note the doubled backslashes (\\) — JSON requires them:

claude_desktop_config.json
{
  "mcpServers": {
    "web-search": {
      "command": "C:\\Users\\YOUR-NAME\\AppData\\Roaming\\npm\\web-search-mcp.cmd"
    }
  }
}
Already have other MCP servers? Don't overwrite the file. Add just the "web-search" block inside your existing "mcpServers" object, separating entries with a comma. The whole file must stay valid JSON.

Save the file and close the editor.

4

Restart Claude and test it

Config changes only load on a fresh launch.

Fully quit Claude (don't just close the window — quit the app entirely) and reopen it. Then ask something that needs the live web, for example:

Prompt
Search the web for today's top tech headlines and summarize them.
✓ You're done when Claude uses the web-search tool and returns current results. If it doesn't appear, re-check the command path in Step 3 and confirm the JSON is valid.
Shortcut

Let an agent handle Step 3 for you

Editing JSON by hand is where most people slip up. Once you've finished Steps 1 and 2, paste the prompt below to an agent with file access (like Claude in this app) and let it wire up the config safely — it will find the binary, merge the entry without clobbering your existing servers, and validate the result.

Give this to your agent
I've installed the web-search MCP server with npm install -g @guhcostan/web-search-mcp. Please add it to my Claude config:

1. Find the installed binary's full path (which web-search-mcp on macOS, where.exe web-search-mcp on Windows).
2. Open my Claude config file:
   - macOS: ~/Library/Application Support/Claude-3p/claude_desktop_config.json
   - Windows: %APPDATA%\Claude-3p\claude_desktop_config.json
   If it doesn't exist, create it with valid JSON.
3. Merge in a web-search server under mcpServers, using the path from step 1 as command. On macOS also add an env.PATH of the standard bin dirs.
4. Preserve any MCP servers already in the file — do not overwrite them.
5. Show me the final file, confirm it's valid JSON, and remind me to fully restart Claude.
