# Pre-Lab Email — "Build Your First AI Agent"

**Subject: Before our "Build Your First AI Agent" lab — 15 minutes of setup**

Hi everyone,

You're signed up for our hands-on lab where you'll go from an empty laptop to a working AI **Event Planner agent** — one that reasons about when to estimate a budget, suggest venues, and update a guest list. No coding experience needed; we go one small step at a time.

To make sure we spend our time building (not installing), please do the following **before you arrive**. It takes about 15 minutes.

**1. Bring a laptop you can install software on.**
You'll need admin rights to install a couple of programs, plus reliable internet. If your laptop is locked down by your IT department, please sort out install permissions ahead of time — this is the #1 thing that blocks people on the day.

**2. Create an IBM ID (if you don't already have one).**
You'll use this to sign in during the lab. Create one in advance at https://www.ibm.com/account — it only takes a minute.

**3. Pre-install Python 3.12 and IBM Bob.** Follow the steps for your operating system below.

---

### 🍎 macOS

**Python 3.12** — Go to https://www.python.org/downloads/ and click the big yellow "Download Python 3.12" button. Open the downloaded `.pkg` file, click Continue → Agree → Install, enter your Mac password, and wait for "The installation was successful."
*(Already have Python 3.12? Skip this — run `python3 --version` in Terminal to check.)*

**IBM Bob** — Download the **macOS** version from https://bob.ibm.com/download (a `.dmg` file), drag Bob into Applications, open it, and sign in with your IBM ID.

---

### 🪟 Windows

**Python 3.12** — Go to https://www.python.org/downloads/ and click the big yellow "Download Python 3.12" button. Run the downloaded `.exe`, and on the very first screen **tick "Add python.exe to PATH"** (this prevents the most common problem people hit), then click Install Now.
*(Already have Python 3.12? Skip this — run `python --version` in PowerShell to check.)*

**IBM Bob** — Download the **Windows** version from https://bob.ibm.com/download (an `.exe` installer), click through the installer, then open Bob from the Start menu and sign in with your IBM ID.

---

### 🐧 Linux

**Python 3.12** — Open a terminal (Ctrl+Alt+T) and run:

```
sudo apt update
sudo apt install python3.12 python3.12-venv python3-pip
```

On Fedora, use `sudo dnf install python3.12` instead. (Type your password if asked — you won't see it as you type, that's normal.)
*(Already have Python 3.12? Skip this — run `python3 --version` to check.)*

**IBM Bob** — Download the **Linux** version from https://bob.ibm.com/download (`.deb` or AppImage), install it, open it, and sign in with your IBM ID.

---

That's it — you don't need to create any API keys or accounts beyond your IBM ID. We'll hand out everything else at the event.

**Stuck on setup?** Don't worry — reply to this email and we'll help, and there'll be helpers in the room too. If a pre-install doesn't work, come anyway; we'll get you going.
